# تطبيق أذكاري - Athkar App

تطبيق عداد الأذكار بتصميم احترافي وواجهة مستخدم أنيقة.

![Flutter](https://img.shields.io/badge/Flutter-3.0+-blue.svg)
![Dart](https://img.shields.io/badge/Dart-3.0+-blue.svg)
![GetX](https://img.shields.io/badge/GetX-4.6+-green.svg)

## ✨ المميزات

- 🕌 **أذكار افتراضية**: مجموعة من الأذكار الأساسية جاهزة للاستخدام
- ➕ **إضافة أذكار مخصصة**: إمكانية إضافة أذكار جديدة مع تحديد الهدف
- 🎯 **تحديد الأهداف**: تحديد هدف رقمي لكل ذكر
- 📊 **تتبع التقدم**: مؤشر دائري يوضح نسبة الإنجاز
- 🎉 **إشعار الإنجاز**: تنبيه عند الوصول للهدف المحدد
- 💾 **حفظ تلقائي**: حفظ التقدم محلياً على الجهاز
- 🌙 **الوضع الليلي**: دعم تلقائي للوضع الليلي والنهاري
- 📱 **تصميم احترافي**: واجهة مستخدم أنيقة ومتجاوبة

## 🚀 البدء

### المتطلبات

- Flutter SDK >= 3.0.0
- Dart >= 3.0.0

### التثبيت

1. **استنساخ المشروع أو إنشاء مشروع جديد:**

```bash
flutter create athkar_app
cd athkar_app
```

2. **استبدال الملفات:**

انسخ جميع الملفات من المجلد المرفق إلى مشروعك.

3. **تثبيت الحزم:**

```bash
flutter pub get
```

4. **تشغيل التطبيق:**

```bash
flutter run
```

## 📱 طريقة الاستخدام

1. **اختيار الذكر**: اضغط على أيقونة القائمة لاختيار ذكر
2. **العد**: اضغط على الدائرة الذهبية للعد
3. **الإنقاص**: استخدم زر "إنقاص" لتقليل العدد
4. **الإعادة**: استخدم زر "إعادة" لإعادة العداد للصفر
5. **إضافة ذكر**: من القائمة، اضغط على "إضافة ذكر"
6. **حذف ذكر**: اسحب أو اضغط على أيقونة الحذف (للأذكار المخصصة فقط)

## 🌙 الوضع الليلي

- **الوضع النهاري**: خلفية فاتحة مع تدرجات ذهبية دافئة
